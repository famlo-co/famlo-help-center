# The Classes list and Registrations

**Classes** in your console shows everything your organization runs, one row per class. Its **Registrations** tab shows every booking across all of your classes. Owners, co-leaders and class organizers can open both. Teachers reach their own classes from **Today** instead.

## Find your way around the Classes list

Open **Classes** in the left rail. It opens on the **List** view.

<Screenshot src="/img/screens/organizations/running-classes-list-list.webp" alt="The Classes list with the Week, Semester and List switch, the Running now, Drafts, Finished and All tabs, and the Select button highlighted" url="famlo.co/co-op/sunnyside-learning/activities?view=list" width={1280} height={800} />

- **Week**, **Semester** and **List** (1) are three views of the same classes.
- The tabs (2), **Running now**, **Drafts**, **Finished** and **All**, each show a count. A tab keeps its count while you're looking at another one.
- **Select** (3) lets you change where several classes show at once. See [Change where many classes show at once](#change-where-many-classes-show-at-once).

A class that meets every week is still one row. Its meetings are listed on the class page, not repeated here. A class split into sections is one row too. Select a row to open the class page, where you'll find its roster, register and meetings. See [Running a class: the class page](/docs/organizations/running/class-page).

Above the views, the buttons **Announce**, **Copy to next semester** and **New class** sit under the page heading. If you've set up a semester, a row of week buttons (**W1**, **W2** and so on) runs across the top. This week is in red and break weeks are shaded. Select a week to see its timetable.

## The three views

| View | What it shows |
| --- | --- |
| **List** | One row per class, with the columns **Class**, **Next meeting**, **Signed up**, **Teacher** and **Status**. This is where you filter, sort and select. |
| **Week** | A Monday-to-Sunday timetable of this week's meetings. Use the arrows to move to the previous or next week, and **This week** to come back. Select a meeting to open its class in a side panel. |
| **Semester** | Every week of the term, with its dates and the classes that meet that week. Select a week to open it in the **Week** view. With no semester set up, you'll see "No semester yet" and **Open the calendar**. |

Every view, tab and filter has its own web address. You can send a co-leader a link to, for example, the classes that still need a teacher.

## Tabs, filters and sorting

The tabs decide which classes the **List** view shows:

| Tab | What's in it |
| --- | --- |
| **Running now** | Published classes that are under way or still to come. This is the tab the list opens on. |
| **Drafts** | Classes you haven't published yet. |
| **Finished** | Classes whose last meeting has passed, and canceled classes. |
| **All** | Every class. |

Then narrow the list with the filters:

- **Needs a teacher** shows only classes still to come that have no teacher.
- **Teacher** and **Location** narrow the list to one teacher or one place.
- **Ages** opens a slider. Drag it to an age range, then select **Apply**. A class with no age range set shows up for every range.
- **Find a class** searches class names. Press Enter to search.

To sort, select a column title: **Class**, **Next meeting** or **Signed up**. Select it again to reverse the order. The list starts sorted by next meeting. In that order, classes with no upcoming meeting come last. The line under the list says how many classes are showing and how they're sorted.

On a phone, the search box sits at the top. Below it, the sort button (it shows the current order, such as **Next meeting**) and **Filter** open small menus. In **Filter**, choose **Any teacher** or **Any location** to clear one filter, then select **Show classes**. **Clear** removes them all.

If nothing matches, you'll see "No classes match that." When a tab is empty, you'll see, for example, "Nothing in Drafts right now." with **Show every class**.

## What the status and teacher columns mean

The **Status** pill says whether a class is a draft and, once published, where families can find it:

| Status | What it means |
| --- | --- |
| **Famlo + site** | Listed on Famlo and on your Famlo website. |
| **Famlo** | Listed on Famlo. You see this instead of **Famlo + site** if your organization has no Famlo website. |
| **Your site** | Listed only on your Famlo website. |
| **Not listed** | Set to show only on your website, but your organization has no website, so it isn't listed anywhere. |
| **Link only** | Not listed anywhere, but anyone with the link can open it and book. |
| **Members only** | Only for families who are members of your organization. |
| **Draft** | Not published yet. Families can't find it. |
| **Finished** | Its last meeting has passed. |
| **Cancelled** | You canceled it. |

In the **Teacher** column, **No teacher** in red means a class that's still to come has nobody teaching it. In **Next meeting**, a class that meets today shows "Today" and its time in red. **Signed up** shows a number like "8 of 40" when the class has a spot limit, or just the number signed up when it doesn't.

To change where one class shows, edit the class. See [Create and publish a class](/docs/organizations/activities).

## The Needs you chip

In the **Week** and **Semester** views, a **Needs you** chip sits beside the view switch, with a count. It counts classes that need you to do something:

- a class meeting today whose register hasn't been taken yet
- a published class that has finished with no register taken
- a draft that hasn't been published yet

Select **Needs you** to open the list showing only those classes. "Showing only: Needs you" appears above the list. Select it to see all your classes again. To take a register, see [Attendance, check-in and the sign-in QR](/docs/organizations/attendance).

A missed week in a class that's still running isn't counted here. **Today** lists those under **Needs you**, and the class's **Sessions** tab marks each one "No register taken", with **Take register**.

## Warnings at the top of the list

**Can't take payment.** A card reading, for example, "2 live classes can't take payment" means some of your published, priced classes can't take card payments right now, usually because something in your payouts setup needs attention. Families can still find these classes and message you, but they can't pay through Famlo. The person who created or claimed the listing sees **Fix payouts**, which opens **Getting paid**. See [Set up getting paid with Stripe](/docs/organizations/getting-paid).

**Still drafts.** A card reading, for example, "3 classes you just changed are still drafts" appears after you use **Select** on drafts. "Changing where a class shows doesn't publish it." Select **Finish drafts** to open the **Drafts** tab and publish them.

## Change where many classes show at once

Use **Select** to change where a group of classes is listed in one go. For example, you might put a whole term on Famlo after preparing it as **Link only**.

1. Open **Classes**, then the **List** view.
2. Select **Select**. A checkbox appears beside each row.
3. Tick the classes you want, or tick the box in the header to select every class shown.
4. In the bar at the bottom (1), choose where they should show: **Famlo + your website**, **Your website only** or **Link only**. If your organization has no website, the first button reads **Famlo** and **Your website only** doesn't appear.
5. To leave without changing anything, select **Cancel**. When you're finished, select **Done**.

<Screenshot src="/img/screens/organizations/running-classes-list-select.webp" alt="The Classes list in select mode with two classes ticked and the bar at the bottom highlighted, showing 2 selected, Famlo + your website, Your website only, Link only and Cancel" url="famlo.co/co-op/sunnyside-learning/activities?view=list&select=1" width={1280} height={800} />

A message confirms the change, for example "3 activities are now on Famlo and your website." Every meeting of a weekly class changes along with it.

:::warning
**Select** changes only where classes show. It doesn't publish drafts. If you selected drafts, the message says how many are "still drafts", and a card with **Finish drafts** appears at the top of the list. Publish each draft from its class editor.
:::

**Who's told:** When published classes move onto Famlo this way, families who follow your organization, have a matching location alert, or saved the earlier class a class was copied forward from (for example last term's) get **one** notice about your organization, not one per class. Your own staff aren't notified. Moving classes off Famlo, or to **Link only**, tells nobody.

## Announce and Copy to next semester

Two buttons at the top of **Classes** start tasks that have their own pages:

- **Announce** opens **Announce to everyone**, a message to the whole organization, not just one class's families. See [Announcements](/docs/organizations/communication/announcements).
- **Copy to next semester** copies this semester's classes into the next one as drafts. It appears only once a semester with classes in it is set up, and only owners and co-leaders see it. If the next semester exists, you confirm the copy. If it doesn't, a form opens that creates the semester and copies the classes in one step. See [Schedule, semesters and breaks](/docs/organizations/running/schedule-and-semesters).

## See every registration

**Registrations** lists every booking across your organization, newest first. "Check-in and payments stay on each activity's roster." It's for looking things up. To check a child in or cancel a booking, open the class.

1. Open **Classes**, then the **Registrations** tab.
2. Under **Show** (1), choose which bookings to list.
3. Under **Activity** (2), choose one class, or keep **All activities**.
4. To download the list, select **Export CSV** (3) at the top of the page.

<Screenshot src="/img/screens/organizations/running-classes-list-registrations.webp" alt="The Registrations tab with the Show and Activity filters and the Export CSV button highlighted, above a table of registrations" url="famlo.co/co-op/sunnyside-learning/registrations" width={1280} height={800} />

| **Show** option | What it lists |
| --- | --- |
| **Confirmed & attended** | Families who are coming or came. This is the default. |
| **Awaiting payment** | Bookings still in the middle of checkout. |
| **Unpaid** | Confirmed places with money still owed. Free places never appear here. |
| **Cancelled & refunded** | Bookings that were canceled or refunded. |
| **Everyone** | Every booking, whatever its status. |

The table has the columns **Registered** (the date of booking), **Activity**, **Who** (the parent who booked), **Attendee** (the child), **Status**, **Amount** and **Payment**. **Payment** shows how a paid booking was paid, such as **Card**, or **Free** or **Unpaid**. Select a class name to open its class page.

The page shows the latest 100 registrations. When there are more, you'll see "Showing the latest 100 of N registrations." Select **Export for the full history** to download all of them. **Export CSV** uses the filters you've chosen and has no limit. To see what's in the file, read [Export your data (CSV)](/docs/organizations/settings/exports).

## The "New booking for" email

Each time a family books one of your classes, the person who created or claimed the listing gets an email with the subject "New booking for [class name]". There's one email for each order, even if the family booked several children at once. It says who booked, when the class starts, how many places they booked, which children are coming, any add-ons, and the status. **View booking** opens the class page.

Taking lots of bookings? Turn this email off in **Account settings** › **Notifications** under **Bookings & sign-ups**. New bookings still appear in **Registrations** and on each roster. See [Notifications](/docs/account/notifications).

## Troubleshooting

**I can't see Classes in my console.**
**Classes** and **Registrations** are for staff who can manage all classes: owners, co-leaders and class organizers. Teachers see their own classes on **Today**. Front desk staff don't see the list, and take attendance from **Today** and **Schedule** instead. See [What staff can do: roles and access](/docs/organizations/members-and-roles).

**I made my classes public with Select, but families still can't find them.**
They're probably still drafts. **Select** doesn't publish. Open the **Drafts** tab and publish each one.

**A class I'm looking for isn't in the list.**
Check which tab you're on. **Running now** leaves out drafts and finished classes. Choose **All**, then clear any filters or search.
