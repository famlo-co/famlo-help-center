# Split a class into sections

Sections let you run one class several ways at once, such as ages 5–8 and 9–12, or a morning and an afternoon group. Each section can have its own ages, days and times, place, teacher, spots and price. Families still see one class and pick a section when they book. You can split a class only before anyone has booked it.

## Add sections to a class

1. Open **Classes**, open the class, then choose **Edit details** in the **•••** menu.
2. In the **When** card, find **Sections** and select **Add a section** (1).
3. The first time, two rows appear. **Section 1** is the class as it is now, and **Section 2** is a copy of it, open and ready to change. "Splits this class into sections: the first is the class as it is now."
4. Give each section a **Section name**, such as "Ages 9-12", and change only what's different.
5. To add another section later, select **Add a section** again. "Starts as a copy of the last one — change only what's different."
6. Select **Save changes** (or **Save draft** for a class that isn't published yet).

<Screenshot src="/img/screens/organizations/classes-sections-editor.webp" alt="The When card in the class editor, with two sections, one opened to its fields, and Add a section highlighted" url="famlo.co/co-op/quillwood-learning-co-op/activities/nature-explorers-fort-myers-fl-2a4t2rudq8/edit" width={648} height={1064} />

Each section is a one-line row with its day, time, place, spots and price. Select **Edit** to open it and **Done** to close it. If you add a row by mistake before saving, select **Don't add this section**.

Once a class has sections, families book a section, never the class itself. The class's own meetings are replaced by its sections' meetings.

:::note
The **Sections** list appears once a class has been saved. For a brand-new class, save it as a draft first, then add sections.
:::

## What each section can set

A section starts with the class's values. Change a field and it carries a **Changed for this section** tag, so you can always see what differs from the class.

| Field | What you set |
| --- | --- |
| **Section name** | The name families pick from, such as "Ages 5-8" or "Afternoon". Every section has its own. |
| **Ages** | The youngest and oldest age for this section. |
| **Teacher** | **Same as the class (…)**, which names the class's teacher, or one of your staff. Only owners and co-leaders can change it. Others see who teaches. |
| **When** | **First meeting** (or **Date** for a one-day class), **Starts** and **Ends**, plus **Meetings** for a weekly class or **Last day** for days in a row. "Repeats the way the class does." |
| **Where** | **Same as the class (…)**, which names the class's place, or another place you've used recently. |
| **Spots** | How many children this section takes. Leave it empty for no limit. |
| **Price** | "The main price. The class's other ways to join follow it." |

A section keeps the class's way of meeting. If the class meets weekly, every section meets weekly. Only the days, times and number of meetings can differ.

## What stays the same for every section

"Extras, refunds, questions and Step Up stay the class's — set once, true for every section." That covers:

- extras and the class's other ways to join, such as single dates or packs
- the refund terms in **If a family cancels**
- registration questions and waivers
- Step Up and other payment options
- the name, description, categories and who can see the class

Change any of these once, in the class editor, and every section follows.

## Which classes can be split

| Class | Can it have sections? |
| --- | --- |
| A class nobody has booked yet | Yes |
| A class that families have already booked | No. The **Sections** list doesn't appear. To offer a new group, create a separate class. |
| A **Program** (families choose days, billed monthly) | No |
| One meeting of a weekly class | No. Sections belong to the whole class. |

If someone books the class while you're editing, the class saves but the sections don't, and you see "Your class is saved, but not its sections: This class: families have booked it, so it can't be split into sections." Once a class has sections, you can keep adding more, even after families book.

## Remove a section

How you remove a section depends on whether anyone has booked it.

**Nobody has booked it:** open the section's row, tick **Remove this section when I save**, then save the class.

**Families have booked it:**

1. Open the section's row and select **Remove this section…**.
2. A panel opens, titled with the section's name, for example **Remove Ages 9-12?**. It says how many families booked the section, and that "The class's other sections stay as they are."
3. Select the cancel button, which names the section, for example **Cancel Ages 9-12 and refund**.

Removing a booked section cancels it. The panel says so: "Removing it cancels it: each one gets a full refund of what they paid by card and is told it's cancelled." The refund is in full whatever your refund terms say, because you're the one canceling. Other sections aren't affected. For what families get back when you cancel, see [Cancel, unpublish or delete a class](/docs/organizations/running/cancel-or-delete).

You can't remove the last section: "A class with sections keeps at least one. To stop it, cancel the class from its page." Canceling the whole class cancels every section.

A removed section that had history stays in the editor as a crossed-out line marked **Cancelled**.

## Find a section on the class page

A class with sections shows a sections card where the meetings usually are.

1. Open the class from **Classes**. A sectioned class is one row in the list.
2. Use the **Section** switch (1) at the top to open one section, or choose **All** (it shows the number of sections, for example **All 2**) to see the whole class.
3. Or select a section in the sections table (2), which says "open one for its own roster and register".

With **All** selected, the roster and money list every section's families, and each row names its section. The **Registered** number under the header adds up the spots across sections, with the spots per section under it, and the price in the header reads "from" the lowest one when section prices differ.

### Teachers in sections

Teachers are set per section. On the class page, the **Sessions** tab shows each section's teacher on its heading. On the **Instructors** tab (owners and co-leaders): "Teachers are set per section. A teacher assigned here teaches every section that doesn't have its own teacher." To give one section its own teacher, open that section.

A teacher who teaches only one section opens straight into it, and sees allergies and medical notes only for the children in their own sections.

## What families see

Families see one class. Its page lists every section's days and places. When the prices differ, the price reads "from" the lowest one, booking fee included. Families choose a **Section** when they book, and at checkout each child is matched to the section that fits their age. Siblings can go to different sections in one order. See [Sections, single dates, packs and other ways to join](/docs/families/booking/ways-to-join) for the family side.

## Troubleshooting

**I don't see Sections in the editor.**
The class has been booked, is a **Program**, or hasn't been saved yet. Save a new class as a draft first. A booked class can't be split, so create a separate class for the new group instead.

**I can't remove the last section.**
A class with sections keeps at least one. To stop the class, cancel it from its page with **Cancel activity** in the **•••** menu.

**I changed the class's price, but one section didn't change.**
That section has its own price, so it shows **Changed for this section**. Edit the section's **Price** directly.
