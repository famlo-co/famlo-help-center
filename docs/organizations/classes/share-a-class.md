# Share a class and add a Reserve on Famlo button

Once a class is published, you can send families its link or share it from the class page. If your organization has a website somewhere else, such as Wix, Squarespace or WordPress, you can add a **Reserve on Famlo** button that takes parents straight to checkout. You can't share a draft, so publish the class first.

## Share the class or copy its link

The class page has two quick ways to pass a class along. Both use the class's page on famlo.co, where families can read about it and book.

1. Open **Classes**, then open the class.
2. Select **Share** at the top of the page. On a computer this opens **Share this class**. On a phone it opens your phone's own share options.
3. Pick where to send it: **Copy Link**, **Email**, **Messages**, **WhatsApp**, **Facebook** or **X**. **Embed** gives you a card for a website (see [Put a class card on your website](#put-a-class-card-on-your-website)).

<Screenshot src="/img/screens/organizations/share-a-class-share-dialog.webp" alt="The Share this class window on a class page, with Copy Link, Email, Messages, WhatsApp, Facebook, X and Embed" url="famlo.co/co-op/thistledown-homeschool-co-op/activities/homeschool-pe-3cwgbdtmgx" width={1280} height={800} />

You'll also find **Copy link** on the meeting card, next to **Message families**. It copies the same famlo.co class page link.

:::tip
The class page link lets parents read everything before they book. If your own page already explains the class and you want parents to go straight to paying, use the checkout link from **Button for your website** instead.
:::

## Add a Reserve on Famlo button to your website

The button sits on your own web page and opens Famlo checkout for this class. Each class has its own button.

1. Open **Classes**, then open the class.
2. Select **•••** (1), then **Button for your website** (2).

<Screenshot src="/img/screens/organizations/share-a-class-menu.webp" alt="A class page with the ••• menu open and Button for your website highlighted" url="famlo.co/co-op/thistledown-homeschool-co-op/activities/homeschool-pe-3cwgbdtmgx" width={1280} height={800} />

3. In **Put it on your website**, keep **Button** selected (1).
4. Under **Says** (2), choose the words: **Reserve**, **Check out** or **Register**. The button reads "Reserve on Famlo", "Check out on Famlo" or "Register on Famlo".
5. Under **Colour** (3), choose **Famlo red**, **White** or **Black**. White suits a busy or colorful page. The preview shows the button as it will look.
6. Select **Copy code**.
7. In your website builder, add an HTML or code block where you want the button, and paste the code. Then publish that page in your builder.

<Screenshot src="/img/screens/organizations/share-a-class-button-builder.webp" alt="The Put it on your website panel with Button, Card and Link, the Says choices and the Colour choices highlighted, and a Famlo red Reserve on Famlo preview" url="famlo.co/co-op/thistledown-homeschool-co-op/activities/homeschool-pe-3cwgbdtmgx" width={1280} height={820} />

The panel says where to paste it: "Code · paste as an HTML block in Wix, Squarespace or WordPress". Each builder names that block a little differently.

### The button keeps itself up to date

You don't need to change the code when the class fills up or closes. The button updates on your site on its own.

| The class is | The button says | A tap takes parents to |
|---|---|---|
| Open | Your chosen words, such as **Reserve on Famlo** | Checkout for this class, in a new tab |
| Full | **Join the waitlist** | The class page on Famlo, where they can join the waitlist |
| Started, canceled, or not taking bookings on Famlo | **Registration closed** | Nowhere. The button can't be clicked. |

The builder explains the waitlist like this: "A full class switches to “Join the waitlist”: everyone waiting is alerted at once, and the first to book gets the spot."

If your website builder removes scripts from pasted code, the button still works. It shows as a plain colored link with your chosen words, without the Famlo mark or the live wording.

## Use the checkout link on its own

**Link** in the same panel gives you the address the button uses. It looks like famlo.co/r/ followed by a short code. Use it in a newsletter, a text message or a menu item on your website.

1. Open the class, then select **•••** › **Button for your website**.
2. Select **Link**.
3. Select **Copy link**.

The link opens checkout for the class, or the class page when the class is full or closed. You'll also find **Copy link** under the button code on the **Button** view.

## What families see when they tap

- **The class is open:** checkout opens in a new tab, with the dates, price and **Pay**. The panel puts it this way: "Opens Famlo checkout in a new tab. Parents sign in with an email code, then pay."
- **The class is full, has started or is closed:** the class page on Famlo opens instead, and it explains why. When the class is full, parents can join the waitlist there.
- **The class is a draft:** your organization's page on Famlo opens with the note "That class isn’t open for registration yet."

Prices at checkout are the same as on famlo.co, including the booking fee if families pay it. See [The booking fee](/docs/organizations/money/booking-fee).

## Put a class card on your website

A card shows the class's photo, name, your organization's name, the date and time, and the price (or "Free"), with **View on Famlo** at the bottom. Tapping it opens the class page on Famlo, where parents read everything and then book. Use a card when you want the class to stand out on a page that doesn't already describe it.

There are two places to get the code:

- **•••** › **Button for your website** › **Card**, then **Copy code**.
- **Share** › **Embed**, which opens **Embed this activity**. Here you can also tick **Hide the price** or **Create “no follow” links**, check the preview, then select **Copy HTML**.

Paste the code into an HTML or code block, the same way as the button. The code sets the card to 450 by 300 pixels. You can change those numbers, and the card fills whatever space you give it.

## If your organization has a Famlo website

If you have a Famlo website, families can already book every class there, so you don't need a button for it. The panel says so at the top: "Your Famlo site already has booking built in. This is for another website Famlo doesn't host."

The button is still useful for other places, such as a partner's site or a church page. When your own domain is connected, the button and the checkout link open checkout on your Famlo website rather than on famlo.co. To see how classes appear on your Famlo website, read [How classes show on your site](/docs/organizations/website/classes-on-your-site).

## Which classes can have a button

- **Published classes only.** **Button for your website** doesn't appear in the **•••** menu on a draft.
- **Not members-only classes.** If **Who can see it** is set to members only, the panel warns: "This class is for members only, so a button on a public website can’t take bookings for it." Choose a different **Who can see it** setting in **Edit details** first.
- **Classes hidden from Famlo search work.** A class set to link only, or shown only on your website, can still have a button. This suits an organization whose families book from its own Wix or Squarespace page.

## Troubleshooting

**I can't find Share or Button for your website.**
The class is still a draft. Publish it first; see [Create and publish a class](/docs/organizations/activities). On a phone, **•••** and **Share** are in the bar at the bottom of the class page.

**The button on my site says "Registration closed".**
The class has started, was canceled, or can't take bookings on Famlo, for example because it registers on another website. Check the class's status and dates on its class page.

**The button on my site looks like a plain link.**
Your website builder removed the script part of the code. The link still opens checkout. Try pasting it into a block meant for custom HTML or embed code.

**I shared the class link, but parents land on the class page, not checkout.**
**Copy link** and **Share** use the class page. For a link that goes straight to checkout, use **Link** in **Button for your website**.
