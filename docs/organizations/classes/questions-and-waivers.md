# Registration questions and waivers

You can ask families your own questions when they register for a class, and have them sign waivers and agreements, such as a release of liability, a late-pickup policy or a photo permission. Set questions on one class, or set defaults in **School settings** › **Registration form** so every new class starts with them. Families answer at checkout, and on the RSVP for a free class too. Waivers and agreements are written once in a library and signed at checkout: they have their own guide, [Waivers and signed agreements](/docs/organizations/classes/agreements).

## Add questions to a class

Questions are for "Anything only this class needs to know, beyond the standard details."

1. Open **Classes**, select the class, then select **•••** › **Edit details**.
2. Under **Everything else**, select **Questions & waivers** (1).
3. Select **Add a question** (2) and type your question.
4. Choose an **Answer type**: **Short answer**, **Paragraph**, **Choose one**, **Choose any** or **Date**. For **Choose one** and **Choose any**, list the options under **Choices — one per line**.
5. Tick **Ask for each child** (3) if the question should be asked once for every child registered, not once per order. Leave it unticked for questions about the family, such as how they heard about you.
6. Leave **Required** ticked if families must answer before they can register, or untick it to make the question optional.
7. Select **Save changes** (or **Save draft** or **Publish** for a new class).

To remove a question, select **Remove** beside it. To see your questions without opening the editor, open the class page's **Listing** tab: the **Registration questions** row lists them, and its **Edit ›** opens the editor at this row.

:::note
A **Choose one** or **Choose any** question with no choices isn't shown to families. Add at least one choice.
:::

If you split a class into [sections](/docs/organizations/classes/sections), its questions and waivers belong to the whole class, so every section asks the same ones.

## Add a waiver or agreement to a class

Below the questions in the same row, **Waivers & agreements** lists the agreements this class asks families to sign. You write the wording once, in your library on **School settings** › **Registration form**. On the class you only pick which ones it uses.

1. In the class editor, open **Questions & waivers**.
2. Under **Waivers & agreements**, select **Pick from your library**, tick the agreements, then select **Add N to this class**. Or select **Write a new one**.
3. Leave **Required** ticked if families must sign it to register, and tick **Per child** to ask once for each child.
4. Save the class.

Families read and sign them at checkout, in a step titled **Before you pay**, and each signer gets a signed copy by email. On the class page's **Listing** tab, the **Waivers & agreements** row sums up the list. For writing agreements, versions, signed copies, exports and more, see [Waivers and signed agreements](/docs/organizations/classes/agreements).

## Editing never changes what families already gave

Answers keep the question as it was worded when the family answered, so you can reword a question or add one mid-term. Families who register from then on see the new version. Families who already registered aren't asked again.

Signed agreements work the same way: each signed copy keeps the exact version the family signed. When you change an agreement's wording, you choose whether families who signed the earlier version are asked to sign again. See [Change an agreement's wording](/docs/organizations/classes/agreements#change-an-agreements-wording).

## Set defaults for every new class

If most of your classes ask the same things, set them once.

1. Open **School settings**, then **Registration form**.
2. Next to **Registration questions**, select **Add** (or **Edit**). Add questions the same way as on a class, then select **Save**.

From a class, you can also select **Save as your school's default** under its questions to make them the ones every new class starts with.

For agreements, turn on **New classes get it** for each one in the **Waivers & agreements** library on the same page. See [Choose which classes ask for it](/docs/organizations/classes/agreements#choose-which-classes-ask-for-it).

Owners and co-leaders can change these defaults. Every new class you create starts with them, and you can still change them on any one class. When a class's questions differ from your defaults, its **Questions & waivers** row is marked as changed for that class.

A class you make by copying another one brings that class's own questions and agreements with it, not your defaults.

### Update the classes you already have

Saving your default questions doesn't change any class you've already made. To apply them:

1. On **Registration form**, find **Classes you already have**.
2. Tick the box that starts "Replace the questions on…". It says how many upcoming classes will change.
3. Select **Update N upcoming classes**, where N is that number.

This replaces the questions on every upcoming class that isn't canceled, including any you set up by hand, so check first. Classes that have already finished aren't touched. "Answers and signatures families already gave are kept as they were." Agreements aren't changed this way: a library agreement offers its own **Add to N upcoming classes** when you make it a default.

## Where to find families' answers

**On the roster.** Open the class and the **Roster** tab. Under a child's row, select **Registration details** to see the answers and what was signed. A **Signed** tag shows when something was signed, and each signed agreement is listed with its version, the name the parent typed and the date. Select one to read the signed copy. Older registrations may instead read "Agreed as [name] on [date]" with the list of terms they agreed to. Answers to an **Ask for each child** question show under that child. Answers asked once per order show once for that order.

**The Forms view.** On a class with agreements, switch the roster from **People** to **Forms** to see every child with their answers and the status of each agreement, and to ask families who haven't signed. See [See who has signed](/docs/organizations/classes/agreements#see-who-has-signed).

**Waiver unsigned.** When a class has agreements and someone hasn't signed a required one, the roster shows a **Waiver unsigned** filter. It lists those registrations, for example families who registered before you added the agreement.

**In a spreadsheet.** On the **Roster** tab, select **Export CSV**. The file has a column for each of your questions, plus **Terms signed by**, **Terms accepted at** and **Terms agreed to**, which show what each family signed. If you reworded a question after families answered it, their earlier answers stay in a column under the old wording.

:::warning
The roster export can include children's health details, in the columns **Allergies**, **Medical notes**, **Medications**, **Dietary**, **Emergency contact**, **Emergency phone** and **Emergency relationship**. Keep the file private and delete it when you're done.
:::

## Troubleshooting

**Families aren't being asked my question.**
Check that the question is on this class, not only in your **Registration form** defaults. Defaults reach only new classes, or upcoming classes after you select **Update N upcoming classes**. Also check that a **Choose one** or **Choose any** question has at least one choice.

**My waivers don't show at checkout.**
Check that the agreement is on this class under **Waivers & agreements**, not only in your library. Also check that **Ask families to sign agreements** is on in **School settings** › **Registration form**. Turned off, "families registering won't be asked to sign anything, including required waivers."

**A family registered before I added a waiver.**
When you add a required agreement to a class, families already registered are emailed a link to sign it. To ask again, open the roster's **Forms** view and select **Ask missing to sign**.

**I don't see "Ask families to agree before they register" any more.**
Waivers live in the **Waivers & agreements** library on **School settings** › **Registration form**, and each class picks from it. See [Waivers and signed agreements](/docs/organizations/classes/agreements).
