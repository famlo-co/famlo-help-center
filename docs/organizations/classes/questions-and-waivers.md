# Registration questions and waivers

You can ask families your own questions when they register for a class, and have them agree to waivers, such as a release of liability, a late-pickup policy or a photo permission. Set them on one class, or set defaults in **School settings** › **Registration form** so every new class starts with them. Families answer and sign at checkout, and on the RSVP for a free class too.

## Add questions to a class

Questions are for "Anything only this class needs to know, beyond the standard details."

1. Open **Classes**, select the class, then select **•••** › **Edit details**.
2. Under **Everything else**, select **Questions & waivers** (1).
3. Select **Add a question** (2) and type your question.
4. Choose an **Answer type**: **Short answer**, **Paragraph**, **Choose one**, **Choose any** or **Date**. For **Choose one** and **Choose any**, list the options under **Choices — one per line**.
5. Tick **Each child** (3) if the question should be asked once for every child registered, not once per order. Leave it unticked for questions about the family, such as how they heard about you.
6. Leave **Required** ticked if families must answer before they can register, or untick it to make the question optional.
7. Select **Save changes** (or **Save draft** or **Publish** for a new class).

<Screenshot src="/img/screens/organizations/questions-and-waivers-class-row.webp" alt="The Questions & waivers row open in the class editor, with one question and one waiver filled in, and the row, Add a question, Each child and Add a waiver highlighted" url="famlo.co/co-op/sunnyside-learning/activities/chess-club-cape-coral-fl-zdpahxf72i/edit" width={670} height={679} />

To remove a question, select the bin icon beside it. You can also change questions without opening the editor: on the class page, open the **Details & questions** tab and edit the **Registration asks** card.

:::note
A **Choose one** or **Choose any** question with no choices isn't shown to families. Add at least one choice.
:::

If you split a class into [sections](/docs/organizations/classes/sections), its questions and waivers belong to the whole class, so every section asks the same ones.

## Add a waiver to a class

1. In the class editor, open **Questions & waivers**.
2. Tick **Ask families to agree before they register**.
3. Select **Add a waiver** (4 in the picture above) and type what families agree to, for example "I agree to the photo permission and release of liability."
4. Leave **Required** ticked if families must agree before they can register. Untick it to make that waiver optional; families then see it marked "(optional)".
5. Add more waivers the same way, then save the class.

On the class's **Details & questions** tab, the same list is in the **What they agree to** card.

### What families see

At checkout or on the RSVP, your waivers appear under "[your organization]'s terms", each with a box to tick. When at least one waiver is required, the family also signs: they enter **Your full name**, then choose **Type it** or **Draw it**. A family who registers several children in one order signs once for that order.

## Editing never changes what families already signed

Each registration keeps the exact wording the family agreed to at the time. As the editor says: "Editing these does not change what anybody already signed — each registration keeps the wording it agreed to." Answers work the same way: they keep the question as it was worded when the family answered.

So you can fix a typo or add a new waiver mid-term. Families who register from then on see the new version. Families who already registered aren't asked again.

## Set defaults for every new class

If most of your classes ask the same things, set them once.

<Screenshot src="/img/screens/organizations/questions-and-waivers-registration-form.webp" alt="School settings with Registration form selected, showing the Registration questions and Agreements rows and the Classes you already have box with its Update button highlighted" url="famlo.co/co-op/sunnyside-learning/settings/registration" width={1280} height={690} />

1. Open **School settings**, then **Registration form** (1).
2. Next to **Registration questions**, select **Add** (or **Edit**). Add questions the same way as on a class, then select **Save**.
3. Next to **Agreements**, select **Add** (or **Edit**). Tick **Ask families to agree before they register**, select **Add an agreement** for each one, then select **Save**.

Owners and co-leaders can change these defaults. Every new class you create starts with them, and you can still change them on any one class. When a class's questions or waivers differ from your defaults, its **Questions & waivers** row is marked as changed for that class.

A class you make by copying another one brings that class's own questions and waivers with it, not your defaults.

### Update the classes you already have

Saving your defaults doesn't change any class you've already made. To apply them:

1. On **Registration form**, find **Classes you already have**.
2. Tick the box that starts "Replace the questions and agreements on…". It says how many upcoming classes will change.
3. Select **Update N upcoming classes** (2), where N is that number.

This replaces the questions and waivers on every upcoming class that isn't canceled, including any you set up by hand, so check first. Classes that have already finished aren't touched. "Answers and signatures families already gave are kept as they were."

## Where to find families' answers

**On the roster.** Open the class and the **Roster** tab. Under a child's row, select **Registration details** to see the answers and the agreement. A **Signed** tag shows when the family signed, and the agreement reads "Agreed as [name] on [date]" with the list of waivers they agreed to. Answers to an **Each child** question show under that child. Answers asked once per order, and the signature, show once for that order.

**Waiver unsigned.** When a class has waivers and someone hasn't signed, the roster shows a **Waiver unsigned** filter. It lists registrations with no agreement on file, for example families who registered before you added the waiver.

**In a spreadsheet.** On the **Roster** tab, select **Export CSV**. The file has a column for each of your questions, plus **Terms signed by**, **Terms accepted at** and **Terms agreed to**. If you reworded a question after families answered it, their earlier answers stay in a column under the old wording.

:::warning
The roster export can include children's health details. Keep the file private and delete it when you're done.
:::

## Troubleshooting

**Families aren't being asked my question.**
Check that the question is on this class, not only in your **Registration form** defaults. Defaults reach only new classes, or upcoming classes after you select **Update N upcoming classes**. Also check that a **Choose one** or **Choose any** question has at least one choice.

**My waivers don't show at checkout.**
Make sure **Ask families to agree before they register** is ticked on the class. Without it, the waivers you typed aren't shown.

**A family registered before I added a waiver.**
They aren't asked again automatically. Use the **Waiver unsigned** filter to find them, then message the family.

**Families didn't type a name.**
Families sign only when at least one waiver is **Required**. If all your waivers are optional, the roster shows the date they agreed, without a name.
