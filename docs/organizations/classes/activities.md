# Create and publish a class

Every class, camp, field trip or program your organization runs is built on one editor page. You fill it in from top to bottom, check the preview of what families will see, and publish when the checklist is complete. Owners, co-leaders and class organizers can create classes. To charge for a class, you also need a way for families to pay (see [Set up getting paid with Stripe](/docs/organizations/getting-paid)).

## Start a new class

1. Open **Classes** in your console, then select **New class**.
2. On **How do you want to start?**, choose a starting point. You can copy a class you've run (1), start from a shape (2), or select **Start blank** (3).

<Screenshot src="/img/screens/organizations/activities-start.webp" alt="The How do you want to start? page with Copy a class you've run, the shapes and Start blank highlighted" url="famlo.co/co-op/sunnyside-learning/activities/new" width={1280} height={800} />

| Starting point | What it sets up |
| --- | --- |
| **Copy a class you've run** | "Dates move to next term. Price, photo, description and rules come with it." Select **Copy ›** on a class. The copy is saved as a draft right away and opens in the editor: "Copied. This is a draft — check the dates, then publish." |
| **Weekly class** | "Same day each week, one price for the term." It starts with six weekly meetings. |
| **Camp** | "Days in a row, priced for the week." Weekdays only. |
| **One day** | "Field trip, workshop or event." |
| **Drop-in program** | "Families pick the dates they come." |
| **Program** | "Families choose their days, billed monthly." See [Programs](/docs/organizations/classes/programs). |
| **Start blank** | The same editor, set to a single day. |

A shape only fills in starting values. You can change anything afterward. If you pick **Camp** and then decide it's one day, just change it.

There is no setting for the kind of activity, such as "field trip" or "class". Families find your classes by their categories, ages, place and dates.

New classes come with your organization's default registration questions and agreements, from **School settings › Registration form**.

## Fill in the editor

The editor is one page of cards. Only **Class name** is required to save a draft. To publish, you'll need what the checklist asks for (see the next section).

### Cover photo and name

Select **Add a cover photo**. "The first thing a family looks at, and often the only one." You can add more photos. The first photo is the cover, and you can drag photos to reorder them. Then type the **Class name**.

### When

Set how the class meets, its dates and its times. A weekly class, a block of days in a row, or dates you pick on a calendar are all set up here. See [Dates, repeats and moving meetings](/docs/organizations/classes/schedules-and-recurring). To split one class into groups by age or time, see [Split a class into sections](/docs/organizations/classes/sections).

### Where & what it is

- **Location**: choose a place you've used before, or **Somewhere new** to search by venue name or address. Add a **Room or meeting spot** if it helps. To stop offering a saved place, use the remove button beside it.
- Online classes: under the place, select **Make it virtual**, or **in person and online** for a hybrid class. Then paste the **Join link**. "Only families who have registered ever see this — on their dashboard and in their confirmation email."
- **Categories**: select **+ Add** and search. You can choose up to 5 from Famlo's list. Families filter search by them.
- **Accessibility**: tick **Sensory-friendly**, **Neurodiversity-friendly** or **Wheelchair accessible**, or select **Something else…** to describe it. "Shown on the listing and searchable — families who need it filter for it."

### Price & spots

Set the price, the number of spots, and any other ways to join, such as single dates or a payment plan. See [Prices, spots and ways to join](/docs/organizations/tickets-and-pricing). A class started as a **Program** has **Days & monthly tuition** here instead.

### How families can pay

- **Card**: "Paid at checkout, to your bank through Stripe." If payouts aren't set up yet, select **Set up payouts**.
- **Step Up for Students**: available on the Scholarship and Website plans. See [Accept Step Up and ESA payments](/docs/organizations/money/step-up-and-esa).
- **Booking fee**: choose **Who pays it** for this class. Families pay a booking fee on paid bookings (3.7% of the price plus $1.79 a ticket, plus Stripe's processing), so you receive the full price you set. You can choose to pay it yourself instead. See [The booking fee, and paying it yourself](/docs/organizations/money/booking-fee).

### Everything else

These rows start "From your settings unless changed". Select **Change** to open a row and **Done** to close it. A row you've set differently from your school's settings shows **Changed for this class**.

<Screenshot src="/img/screens/organizations/activities-everything-else.webp" alt="The Everything else card with Who can see it open, showing the four visibility choices" url="famlo.co/co-op/sunnyside-learning/activities/little-scientists-lab-cape-coral-fl-xpfdyziifx/edit" width={808} height={1128} />

**Who can see it**

| Choice | Who can find it |
| --- | --- |
| **Famlo + your website** (just **Famlo** if you have no website) | "Families find it in Famlo search and on your website." |
| **Your website only** | "Listed on your website, kept out of Famlo search." Offered once your organization has a website. |
| **Members only** | "Only members of your group." |
| **Link only** | "Listed nowhere. Only people you send the link to can open it." |

The other rows:

- **Ages**: set **Youngest** and **Oldest**, or leave them as "Any".
- **Sign-ups**: **Sign-ups close** is optional. "After this, the listing stays up and the button stops." **Sign-ups after the class starts** is on for new classes. A family who joins late pays for the dates that are left. Turn it off and registration closes when the class starts.
- **If a family cancels**: your refund terms. They're required for a paid class. See [Refund terms](/docs/organizations/classes/refund-terms).
- **Questions & waivers**: see [Registration questions and waivers](/docs/organizations/classes/questions-and-waivers).
- **Extras** and **Family rates**: see [Prices, spots and ways to join](/docs/organizations/tickets-and-pricing).
- **Who teaches**: in **Who runs it?**, pick someone on your staff, **Someone else…** (type **Their name**), or **Nobody in particular**. When you pick a staff member, the box **Add [name] to this activity's instructors** (with their name) is ticked. Leave it ticked to give them the class's questions and roster. A typed name is added to your Staff page as a profile with no sign-in. See [Add staff](/docs/organizations/team/add-staff).
- **Week-by-week plan**: select **Open**. See [Week-by-week plan](/docs/organizations/classes/week-by-week-plan).
- **Reminders**: "Families get an email the day before and a heads-up in Famlo an hour before each meeting." **Remind the teacher to take attendance** sends a reminder on each meeting day while the register is incomplete. It goes to the people who run your classes and check-in.

### Description

- Write what children will do and why it's worth coming. "Start a line with - for a bullet or 1. for a numbered step, and wrap text in \*\*asterisks\*\* for bold." Links aren't allowed, because families book through Famlo.
- **What to bring** and **What's included**: one item per line.
- **Highlights (optional)**: up to four, each with an icon, a short title and one detail line. They show as tiles under the photo.

You don't need to repeat the price, ages or refund terms. The class page shows them from your settings above.

## Check what families will see, and publish

Beside the editor (below it on a phone), **Families will see** shows the class card as it appears in search. Its price is the all-in price families pay, booking fee included.

Under it, a checklist shows what's left before families can book (1):

- Name, time and place
- A price, or free
- Refund terms (paid classes)
- A way for families to pay (paid classes)
- A cover photo
- A description
- Categories, so search finds it

<Screenshot src="/img/screens/organizations/activities-editor.webp" alt="The New class editor with the Families will see checklist and the Publish and Save draft buttons highlighted" url="famlo.co/co-op/sunnyside-learning/activities/new?start=weekly" width={1440} height={900} />

Then use the buttons (2):

| Button | What it does |
| --- | --- |
| **Publish** | Saves the class and makes it visible to families: "Published. Families can find it now." If anything on the checklist is missing, Famlo saves a draft instead and shows what's left. |
| **Save draft** | Saves without publishing: "Draft created. Nothing is published until you say so." Your draft opens on its class page. |
| **Save changes** | On a published class, saves your edits. Once families have booked, the button reads **Save · review what families see**. It shows you the changes before you tell those families. See [Dates, repeats and moving meetings](/docs/organizations/classes/schedules-and-recurring). |
| **Unpublish** | Hides a published class. "The class page stops showing to families, including anyone with the link." |
| **Preview as a family** | Opens the class page as families see it, once the class is saved. |

To edit a class later, open it from **Classes**, then choose **Edit details** in the **•••** menu. A Teacher can also edit the classes they're assigned to, but can't create or delete classes.

## Suggestions in the editor

Once a class is saved, the **Price & spots** card sometimes shows one suggestion, based on how the class is doing:

- The class is full: **Add spots**.
- Lots of families looked at a weekly class but few signed up: **Add single dates**.
- The term price is a lot to pay at once: **Add a payment plan**.

The button only fills in the form, and nothing changes until you save the class. **Not now** hides that suggestion for this class. Select **Undo** if you change your mind.

## Troubleshooting

**I pressed Publish but the class is still a draft.**
Something on the checklist was missing. Your work is saved as a draft, and its class page shows what's still needed. Fill those in, then publish.

**"A way for families to pay" won't tick.**
Your organization can't take payments yet. Select **Set up payouts** under **How families can pay**, or see [Set up getting paid with Stripe](/docs/organizations/getting-paid). Free classes don't need this.

**I don't see Classes or New class.**
Your role doesn't include creating classes. Owners, co-leaders and class organizers can create them. See [What staff can do](/docs/organizations/members-and-roles).

**Families say they can't find the class.**
Check **Who can see it**. **Your website only**, **Members only** and **Link only** keep a class out of Famlo search.

**I don't have the Your website only choice.**
It appears once your organization has a website. See [Your Famlo website](/docs/organizations/website/overview).
